Roleplay Manager has three moving parts: a **provider**, a **character** and a
**conversation**. You only need to set them up once.

## 1. Connect a provider

Open **System → Providers** and add one of these:

- **Ollama** on the same computer: `http://localhost:11434`.
- **OpenAI-compatible**: any endpoint with a URL and a key, such as LM Studio,
  OpenRouter or a self-hosted gateway.

Use **Test connection**, then choose a default model. You can override the model
per conversation later.

## 2. Create a character

Open **My characters → Create character**. Give it a name, a short description,
a greeting and, optionally, an image and personality cards. Every edit creates a
new version, so you can go back later.

You can also import a character from a JSON file.

## 3. Start a conversation

Open the character and send the first message. From a conversation you can:

- Edit or regenerate a reply.
- Rewind to an earlier message.
- Create a branch to explore another direction.
- Change the model, memory mode and chat style for that conversation.
