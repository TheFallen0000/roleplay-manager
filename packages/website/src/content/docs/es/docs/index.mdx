## Empieza aquí

Roleplay Manager se ejecuta en tu equipo. Tus personajes, chats, memorias,
resúmenes e imágenes viven en una base SQLite dentro de `data/`, y la app habla
con el proveedor de IA que elijas.

Si es tu primera vez:

1. [Instala el paquete portátil](/es/docs/getting-started/installation/windows/).
2. [Conecta Ollama o un proveedor compatible con OpenAI](/es/docs/guides/providers).
3. [Crea tu primer personaje y empieza a chatear](/es/docs/getting-started/first-steps).
