Install on Windows

Download the portable package, unzip it and run the launcher. No Node.js, no installer, no account.

Windows 10/11 · x64 Version 1.47.0 · About 5 minutes

Before you start

Roleplay Manager runs on your computer. You need a 64-bit Windows 10 or 11 PC and an AI provider: Ollama on the same machine, or any OpenAI-compatible endpoint with your own key.

What Details
Download 62 MB ZIP
Unzipped About 200 MB
Admin rights Not required
Node.js Not required — the runtime is included
Your data data/ inside the app folder
Keep the folder somewhere permanent

Use a folder you can write to, such as Documents\RoleplayManager. Avoid running it from inside the ZIP: Windows unpacks to a temporary folder and your data becomes harder to find.

1. Download the package

Download the Windows x64 package from the latest release. The file is called roleplay-manager-1.47.0-win-x64.zip.

Download for Windows (x64) · 62 MB

Need Linux or macOS? See all platforms.

2. Unzip it somewhere permanent

Right-click the ZIP and choose Extract All…, then move the folder to Documents\RoleplayManager. Keep the whole folder together; the launcher, runtime and versions live inside it. 

RoleplayManager/
├── data/        ← your story
├── backups/     ← safety copies
├── versions/    ← installed versions
└── start.cmd

3. Open the launcher

Double-click start.cmd. A console window opens and the browser should open at http://localhost:3001 when the app is ready. 

start.cmd

If the browser does not open, visit http://localhost:3001 manually. Keep the console window open while you use the app; closing it stops the server.

4. Connect your AI

In the app, open System → Providers, add Ollama or an OpenAI-compatible endpoint, and use Test connection. Then choose a default model and create your first character.

Next: connect a provider →

If Windows warns you

“Windows protected your PC”

The app is not code-signed, so SmartScreen may show a warning on first launch. Only continue if you downloaded the file from the official GitHub release.

Click More info → Run anyway. This is a one-time step for the launcher.

If something goes wrong

  • The browser does not open: go to http://localhost:3001 manually. If it still fails, check the console window for an error.
  • Port 3001 is already in use: close the app using it, or start Roleplay Manager with a different PORT.
  • The launcher closes immediately: unzip the package again; running start.cmd from inside the ZIP is the most common cause.
  • You use macOS or Linux: follow the platform-specific guide instead.

Instalar en Windows

Descarga el paquete portátil, descomprímelo y ejecuta el lanzador. Sin Node.js, sin instalador, sin cuenta.

Windows 10/11 · x64 Versión 1.47.0 · Unos 5 minutos

Antes de empezar

Roleplay Manager se ejecuta en tu ordenador. Necesitas un PC con Windows 10 u 11 de 64 bits y un proveedor de IA: Ollama en el mismo equipo, o cualquier endpoint compatible con OpenAI con tu propia clave.

Qué Detalles
Descarga ZIP de 62 MB
Descomprimido Unos 200 MB
Permisos de admin No hacen falta
Node.js No hace falta: el runtime va incluido
Tus datos data/ dentro de la carpeta de la app
Guarda la carpeta en un sitio permanente

Usa una carpeta donde puedas escribir, como Documentos\RoleplayManager. Evita ejecutarlo desde dentro del ZIP: Windows descomprime en una carpeta temporal y tus datos se vuelven más difíciles de encontrar.

1. Descarga el paquete

Descarga el paquete de Windows x64 desde la última release. El archivo se llama roleplay-manager-1.47.0-win-x64.zip.

Descargar para Windows (x64) · 62 MB

¿Necesitas Linux o macOS? Ver todas las plataformas.

2. Descomprímelo en un sitio permanente

Haz clic derecho en el ZIP y elige Extraer todo…, y luego mueve la carpeta a Documentos\RoleplayManager. Mantén la carpeta completa: el lanzador, el runtime y las versiones viven dentro. 

RoleplayManager/
├── data/        ← tu historia
├── backups/     ← copias
├── versions/    ← versiones
└── start.cmd

3. Abre el lanzador

Haz doble clic en start.cmd. Se abre una ventana de consola y el navegador debería abrir http://localhost:3001 cuando la app esté lista. 

start.cmd

Si el navegador no se abre, visita http://localhost:3001 a mano. Mantén la consola abierta mientras usas la app; al cerrarla se detiene el servidor.

4. Conecta tu IA

En la app, abre Sistema → Proveedores, añade Ollama o un endpoint compatible con OpenAI y usa Probar conexión. Después elige un modelo por defecto y crea tu primer personaje.

Siguiente: conectar un proveedor →

Si Windows te avisa

«Windows protegió tu PC»

La app no está firmada, así que SmartScreen puede mostrar un aviso en el primer arranque. Continúa solo si descargaste el archivo desde la release oficial de GitHub.

Pulsa Más información → Ejecutar de todas formas. Es un paso único para el lanzador.

Si algo falla

  • El navegador no se abre: entra en http://localhost:3001 a mano. Si sigue fallando, mira el error en la ventana de consola.
  • El puerto 3001 está ocupado: cierra la app que lo usa o arranca Roleplay Manager con otro PORT.
  • El lanzador se cierra al instante: vuelve a descomprimir el paquete; ejecutar start.cmd desde dentro del ZIP es la causa más común.
  • Usas macOS o Linux: sigue la guía de tu plataforma.
