02 · Ajustes

Cómo se activa

El presupuesto y la profundidad deciden qué entradas entran en cada respuesta.

Nivel de libro
Escaneo recursivo
Las entradas activadas pueden activar otras, hasta 3 niveles. Útil para cadenas de lore; puede aumentar el contexto.

Cómo se activa una entrada

Si una clave primaria aparece en los últimos mensajes, la entrada entra. Las claves secundarias y la lógica selectiva afinan el disparo. Las entradas constantes entran siempre.

Qué es una clave

Una palabra o frase que, si aparece en los mensajes recientes, hace que la entrada entre en el prompt. Las secundarias solo filtran cuando la primaria ya ha coincidido.

Presupuesto

Si el libro activa más texto del que cabe, las entradas con menor prioridad se quedan fuera. El manifiesto del contexto lo muestra.
